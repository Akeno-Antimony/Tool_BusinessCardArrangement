# 名刺PDFデータ抽出・Excel自動整理ツール

スキャンした名刺のPDFファイル群から、最新の生成AI（Gemini API）を用いて記載情報を高精度に読み取り、Excelファイルへ自動で整理・出力するPythonスクリプトです。

## 主な機能

- **複数ファイルの一括処理**: GUIのファイル選択ダイアログで、処理したい名刺のPDFを複数同時に選択できます。
- **高精度なデータ抽出**: `gemini-3.8-flash` モデルを使用し、画像化された名刺から「会社名」「部署・役職」「氏名」「メールアドレス」「電話番号」「住所」を構造化データ（JSON）として抽出します。
- **Excelへの新規作成・追記**: 出力先のExcelファイルをダイアログで選択可能。既存のファイルを選べば末尾に自動追記され、キャンセルすれば新規ファイルとして作成されます。
- **エラーハンドリング**: APIの混雑時（503エラー）を検知し、自動で一定時間待機・リトライする安全設計です。

## 動作環境・前提条件

- Python 3.8 以上推奨
- Google Gemini API のAPIキー

## セットアップ

### 1. 必要なライブラリのインストール

コマンドプロンプトまたはターミナルを開き、以下のコマンドを実行して必要なパッケージをインストールします。

```bash
pip install pymupdf google-genai pillow pandas openpyxl python-dotenv
```
*(※ `openpyxl` は Pandas が Excelファイル を読み書きするために裏側で必要になります)*

### 2. 環境変数の設定

プロジェクトの同じフォルダに `.env` という名前のファイルを作成し、取得した Gemini API キーを記述します。

**.env ファイルの記述例:**
```env
GEMINI_API_KEY=あなたの_API_キーをここに貼り付けてください
```

## 使い方

1. コマンドラインからスクリプトを実行します。
   ```bash
   python business_card_pdf_to_excel.py
   ```
2. **【1/2】PDFファイルの選択**:
   ダイアログが表示されるので、読み取りたい名刺のPDFファイルを選択してください（複数選択可）。
3. **【2/2】出力先Excelの選択**:
   データを追記したい既存のExcelファイル（例: `名刺データ一覧.xlsx`）を選択してください。
   新しく作りたい場合はダイアログの「キャンセル」を押すと、自動的に新規作成モードになります。
4. 処理が開始されます。ターミナル上で進捗が確認でき、完了するとポップアップで通知されます。

## 注意事項

- **APIの利用枠**: 無料枠で利用する場合、短時間に大量のリクエストを送ると制限に引っかかる可能性があります。本ツールはエラー時の自動リトライ機能を備えていますが、大量処理時はご注意ください。
- **読み取り精度**: 名刺のデザインやスキャン時の解像度によっては、一部の項目が正確に読み取れない（または `null` になる）場合があります。出力されたExcelデータは適宜目視で確認することをお勧めします。
- スキャンするPDFは、1ページ目に名刺の表面がくるようにしてください。
